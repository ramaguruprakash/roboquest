🤫 Here's a secret: computers aren't smart

They can't think of anything all by themselves! But they are amazing at following instructions — exactly, super fast, and they never, ever get tired.

Coding is teaching a computer what to do.

📝 You teach it with instructions

You write a list of steps, and the computer follows your list from top to bottom. Watch Robo follow this one:

A list like that is called a program — and writing programs is coding!

🌍 A set of instructions is a language

Instructions that people and computers both understand make a programming language. Grown-up coders use languages with funny names like Python 🐍, JavaScript ⚡ and Scratch 🐱.

We're starting with one made just for fun: the Robo language — and you're about to learn it!
